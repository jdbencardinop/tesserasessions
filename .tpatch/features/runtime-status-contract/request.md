## Description

Expose a side-effect-free, versioned batch JSON status-provider contract for external orchestrators such as tws. Query live runtime observations by opaque query ID plus verified path and optional Git hints; return freshness, match evidence, raw runtimes, and separate runtime_presence and agent_state aggregates without guessing cwd-less sessions.
