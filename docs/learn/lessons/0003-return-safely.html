Three verbs, three intentions

Attach

Return to a stored matching live runtime when the preferred backend has one. Otherwise, fall back to the historical session's native resume command. 

tss attach codex-demo123 --print

Resume

Resume is the source-native fallback stored on a historical session. You normally reach it through tss attach, which preserves source-specific environment such as CODEX_HOME.

Open

Create a new Herdr workspace or tmux session in the same project directory. This does not resume the old conversation. 

tss open codex-demo123 --print

Practice: inspect, preview, compare

  1. Reconfirm the selected record: 
    tss show codex-demo123
  2. Preview the default return path: 
    tss attach codex-demo123 --print
  3. If you need to compare a backend explicitly: 
    tss attach codex-demo123 --backend tmux --print
tss attach codex-demo123 --backend herdr --print
  4. Execute only after the command, project path, and identity match your intent: 
    tss attach codex-demo123

Interactive Removing --print may attach the terminal or start the source agent. Command preview is the review boundary.

Apply the same boundary to live control

tss send codex-demo123 "summarize the current blocker" --print
tss read codex-demo123 --lines 80 --print
tss run codex-demo123 --print -- go test ./...

These commands require a suitable live runtime. Preview mode lets you inspect backend targeting and quoting before any input or command is sent.
